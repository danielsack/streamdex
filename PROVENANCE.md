# Provenance

Streamdex is a personal experiment in ways of working with agentic workflows, based on Todd Dailey's streamdeckcodex, https://github.com/twidtwid/streamdeckcodex, version 0.2.4, upstream revision `c8f6b2eedda522b77ad0f9a87f5037cfb062999f`.

This is a clean repository with new history, not a claim of an independent implementation. The upstream TypeScript task store, native Accessibility/targeting implementation, command and reasoning support, tests and visual utilities remain MIT licensed. The original Copyright (c) 2026 Todd notice is retained in LICENSE.

Streamdex-specific changes include the task-card design and motion, persistent read ledger, pending-question tracking, Mobile/Plus layouts, dynamic Voice controls, lighting presets, packaging/installation tooling and media/demo. Personal configuration and extracted Codex artwork were removed from the publication candidate. Glyphs use Lucide or simple original geometry.

The supplied physical-device photo is used with the owner's authorization. The film and procedural device model were created for this project using fictional conversations. Three.js is MIT licensed. Product names identify compatibility and do not imply affiliation or endorsement.

The publication candidate removes unused upstream global permission-mode mutation, automatic Full Access confirmation, and autonomy/publication workflow presets. Request-specific deliberate hold controls and read-only approval observation remain. Native fixture handlers compile into a separate test helper and are absent from distributed executables. Synthetic model identifiers are explicitly labeled as test data.
