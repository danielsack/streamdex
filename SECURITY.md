# Security and privacy when experimenting

This experimental snapshot is provided as is. No support, vulnerability-response service, security updates, or ongoing maintenance is offered.

If you find a security problem, stop using the affected behavior. Do not publish secrets, real task content, raw profiles, databases, app captures, or unredacted logs. Keep sensitive details private.

When adapting the code, changes involving target identity, permissions, native app control, package integrity, or rollback require targeted regression tests and a renewed artifact audit before distribution.
